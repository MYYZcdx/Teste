# Luca Suque — Produtor Musical

Site one-page do **Luca Suque (Chamaa LS)** — produtor musical, tecladista e engenheiro de mix & master.

Estático (HTML + CSS + JS puro), sem build. Abra `index.html` no navegador ou publique em qualquer host estático (GitHub Pages, Netlify, Vercel).

## Estrutura
- `index.html` — página e conteúdo
- `assets/css/style.css` — estilos (cores e fontes em `:root`)
- `assets/js/main.js` — preloader, cursor, reveals, parallax, contadores, lightbox e formulário
- `assets/img/` — fotos do Instagram do cliente

## Contato
O formulário monta a mensagem, copia para a área de transferência e abre o Direct do Instagram (`ig.me/m/luca.suque`). Para usar WhatsApp ou e-mail, troque o link em `main.js`.
